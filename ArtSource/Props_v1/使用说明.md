# 零点值班道具模型

> Source-stage modeling notes. The props are now integrated into the maintained
> Unity scene. See `Docs/PROJECT_GUIDE.md` and the root README for current behavior.

打开 `ZeroDuty_Props_v1.blend`，在 Blender 顶部切换场景：

- `01_ASSETS_real_scale`：实际尺寸模型，每件道具独立集合；选择集合中的根空物体可整体移动。
- `02_PRESENTATION`：成品展示，使用模型集合实例并调整了展示比例，不作为游戏实际尺寸。

包含三幅监控相框、展开与合上的记录本、检查夹板、便签、折叠纸条、咖啡罐、口粮包装、饼干、机器人摆件，共 12 组。

三幅相框使用已保存的 Unity `first` 场景中三个原监控相机导出的正常状态截图，图片已打包在 blend 内，也保留在 Textures 文件夹。不是概念图替代场景截图。

记录用品仅有英文占位标题和横线，剧情内容尚未填写。文字保留为可编辑对象。当前为 Blender 模型源文件，尚未放入 Unity 场景、添加碰撞体或交互；导入游戏前需要导出模型，并为 Unity 配置兼容材质（Blender 程序化材质不会完整自动转换）。

`Props_Preview.png` 是本批模型的实际渲染图。`build_props.py` 为可重复生成源脚本。
