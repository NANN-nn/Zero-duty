# Chinese UI font

Noto Sans SC Regular, unmodified static OpenType font.

Source: https://github.com/notofonts/noto-cjk/blob/main/Sans/SubsetOTF/SC/NotoSansSC-Regular.otf

License: SIL Open Font License 1.1; see `OFL.txt` alongside the font.
The font is bundled with the game so Chinese works offline and does not depend
on fonts installed on the player's computer. English UI and English handwritten
notes retain their original fonts. The title is **END OF SHIFT** in English
and **夜尽之前** in Simplified Chinese.
