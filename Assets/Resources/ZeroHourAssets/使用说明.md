# 零点值班 · Unity 素材包

更新时间：2026-09-13。此包是模型整理与首轮独立道具交付，不含完整游戏逻辑。

## 文件与内容

- `Models/ZH_SCENE_Station_Complete.fbx`：保持实验室原布局的整套场景，设备以父子层级组织，未合并成一个不可拆分的大网格。
- `Models/ZH_ENV_*.fbx`：63 个原有设备/组件，包括电脑、显示器、销毁器、工作台、柜体、门组件等。
- `Models/ZH_PROP_TOOL_*.fbx`：检测仪、脉冲枪和电子日志板。
- `Models/ZH_PROP_ANOMALY_*.fbx`：异常照片、黑色渗出物和静态鬼影。
- `Models/ZH_PROP_LAB_*.fbx`：样本罐、玻璃碎片、运输箱、试管、试管架、数据模块和托盘。
- `Models/ZH_PROP_UTILITY_*.fbx`：线缆、接头、通风盖板、接线盒及收纳盒。
- `模型清单.csv`：所有模型的新文件名、类别、源对象、三角面数、尺寸及旧文件名对照。
- `素材预览.html`：当前道具实际 Blender 渲染图目录。不是概念图；照片道具内部使用 AI 生成照片贴图，其制作说明单独存放。
- `Textures`、`materials.json`：导出图像及材质参数；请一同保留。
- `Editor/ZeroHourAssetSetup.cs`：显式菜单触发的材质/Prefab 生成与检查脚本。

总计 88 个 FBX，包括整套场景。部分设备是嵌套关系：例如工作台包含电脑，而电脑也单独导出。因此不要把全部 FBX 一起拖入同一位置，否则会出现重复物体。

## Blender 源文件

当前源文件仍是 `F:\零点值班\Blender场景\V9\ZERO_HOUR_Station_V9_REDESIGN.blend`，未另建一批版本。

打开后为原实验室。切换场景到 `ASSET_LIBRARY` 可以查看新增独立道具。原场景的设备分组位于 `70_UNITY_ASSET_ROOTS`，新道具位于 `80_INDEPENDENT_GAME_PROPS`。移动设备请选对应父级 Empty；只选子网格会只移动那个零件。

检测仪、脉冲枪已按最新要求缩至上一版的 48%（长、宽、高均同比例缩小），保留竖放检测仪、斜放脉冲枪，原柜体大小不变。短卡扣和低底座同步缩小，柜内新增无文字状态面板、散热槽和充电接口。卡扣属于柜体，工具可独立移动；独立工具导出与柜内工具尺寸一致。尚未加入手部抓取和物理碰撞检测。

## Unity 使用

1. 将本文件夹整体复制到项目的 `Assets/ZeroHourAssets`，文件夹名字须与脚本约定一致。若该目录已存在，请先保留你自行修改的材质和 Prefab，避免覆盖。
2. 等待 Unity 完成模型和脚本导入，再执行菜单 `Tools > Zero Hour > Build Materials and Prefabs`。
3. 脚本会在此包内创建 `Materials`、`Prefabs`，并输出 `UnityValidation.json`。重复执行会更新同名生成文件；请把自行改造的版本复制到另外的目录。
4. 整体场景用 `Prefabs/ZH_SCENE_Station_Complete.prefab`；单独摆放用对应的 `ZH_ENV_` 或 `ZH_PROP_` Prefab。移动父级可带动设备零件；编辑内部结构可展开层级。需要直接修改模型实例层级时，先在 Unity 中 Unpack Prefab。

FBX 采用米制、Y 向上。脚本面向 Built-in / URP，不支持 HDRP 自动转换。没有自动创建碰撞体、拾取脚本、门控制或灯光。

## 已验证与尚未验证

88 个文件均完成 Blender FBX 回读检查，尺寸包围盒、网格数量、三角面数量、父级移动和材质槽检查通过；引用贴图文件齐全。详情见 `FBX回读检查.json`。完整实验室约 38.6 万三角面，最终运行性能仍取决于 Unity 的材质、灯光、遮挡剔除和目标硬件，不能仅凭面数保证帧率。

本机 Unity 验证启动被许可证服务连接失败阻断，所以未完成 Unity 实际导入/编译验证。导入脚本已提供，但需在可正常启动的 Unity 项目中执行并检查报告；这与 FBX 回读检查不是同一件事。

## 视觉与功能限制

- 新道具是当前首轮真实模型，不代表已达到概念图的全部细节。预览可用于逐件评审。
- Blender 程序化材质细节未完整烘焙，Unity 使用颜色、金属度、粗糙度、发光与贴图的近似材质。玻璃是透明混合近似，非 Cycles 折射；导入后不会自动复现 Blender 的全部质感和灯光。
- FBX 不带 Blender 灯光及其开关驱动。原 `.blend` 保留这些设置，Unity 内需重新配置可控灯光。
- 鬼影为静态、无骨骼模型。移动、烟雾、消散、受击与死亡等效果未制作；黑色渗出物也没有扩散动画。
- 破损罐和碎片是独立预制几何，不是实时破碎模拟。门、罐盖等零件可分开控制，但没有导出交互动画。
- 原布局保留；新增杂物没有随机散放进原实验室。请按玩法需求自行摆放。
