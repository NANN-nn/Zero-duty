## 中文介绍

### 今晚，轮到你值班

上一班的人已经走了。地底下只剩下你、三台监控，以及一本留在桌上的员工手册。

墙上的照片记录着房间原本的样子。监控里的变化，有时小到让你怀疑自己的记忆。走廊里多出来的东西、泄漏的气体、失灵的电路，都得在规定时间内处理。你可以回到座位上，再确认一遍。

但有些东西，已经离你更近了。

**《夜尽之前》是一款以地下实验设施为背景的单人第一人称恐怖解谜游戏。**在观察与行动之间往返，拼起前任值班者留下的线索，直到这场夜班把最后一个选择交到你手上。

### 一场夜班，不止是盯着屏幕

| 观察 | 处理 | 承受 |
| :--- | :--- | :--- |
| 切换三路监控，对照墙上的正常状态照片，发现不该出现的变化。 | 离开控制室，搬走异常物品、调节气阀、修复电闸，使用枪和探测器。 | 任务有时限。灯光与屏幕逐渐失常，鬼影也会在你迟疑时逼近。 |

```text
阅读手册 → 查看监控 → 发现异常 → 前往处理 → 回到监控
                         ↓
                   最后的选择 · 两种结局
```

- **异常物品**：把不属于这里的东西送进实验室的粉碎机。
- **气阀调节**：按住让压力上升，松开让它回落，在安全区域里稳住三个通道。
- **电闸修复**：旋转线路连接器，观察彩灯提示，再按顺序操作拉杆。
- **射击与探测**：面对射击室的异常身影，也别放过样本中的异样。
- **最后的抉择**：记录是否应该被送出去？设施是否应该被封锁？两种选择通向不同结局。

### 房间里也有人留下过生活

翻开手册，读一张折起的便签，播放一小段音乐，或者停下来吃点东西。五个藏在场景里的小机器人可以收集，收齐后会在控制室桌上一起展示。

故事藏在这些物件和笔记里，也藏在主角时不时冒出的心里话中。

## English

### Tonight, you're on duty

The last shift has gone home. Down here, it's just you, three monitors, and an employee handbook left on the desk.

The photographs on the wall show how the rooms should look. Changes on the monitors can be small enough to make you question your memory. An object in the corridor. A leaking valve. A failed circuit. Each incident needs your attention before time runs out. You can always return to your seat and check again.

But something else has been getting closer.

**End of Shift is a single-player, first-person horror puzzle game set in an underground research facility.** Move between observation and action, piece together the previous workers' notes, and face one final decision before the night is over.

### More than watching a screen

| Observe | Respond | Endure |
| :--- | :--- | :--- |
| Switch between three feeds and compare the rooms with their normal-state photographs. | Leave the control room, dispose of objects, regulate pressure, repair power, and use your gun and scanner. | Work against the clock as lights flicker, screens break down, and a shadow closes in. |

```text
Read the handbook → Watch the feeds → Spot a change → Respond → Return to the monitors
                                             ↓
                                  One final choice · Two endings
```

- **Unwanted objects:** carry what doesn't belong to the laboratory disposal unit.
- **Pressure regulation:** hold to raise pressure, release to lower it, and stabilize all three channels.
- **Power restoration:** rotate the circuit connectors, follow the colored light sequence, and operate the levers in order.
- **Shooting and scanning:** confront the figure in the shooting room and investigate irregular specimens.
- **A final decision:** send out the records or seal the facility. Each choice leads to its own ending.

### People lived here, too

Read a folded note, play a short piece of music, grab a snack, or search for the five small robots hidden around the station. Collect them all to see them displayed together on the control-room desk.

The story unfolds through those objects, the handbook, scattered notes, and the protagonist's thoughts.

## 开始体验 / Get started

**最终交付版 / Final delivery:** `final-delivery-native-ui`  
**Unity:** `6000.4.10f1` · **输入 / Input:** 键盘与鼠标 / Keyboard and mouse

仓库提供完整 Unity 源项目，当前通过 Unity 编辑器运行。  
This repository contains the complete Unity source project. Run the current delivery in the Unity Editor.

### 1 · 下载 / Clone

安装 Git 与 Git LFS，然后执行。部分 Blender 源文件使用 LFS，推荐克隆获取完整文件。  
Install Git and Git LFS, then run the following. Some Blender sources use LFS; cloning retrieves the complete files.

```bash
git lfs install
git clone --branch final-delivery-native-ui --single-branch https://github.com/NANN-nn/Zero-duty.git End-of-Shift-Final
cd End-of-Shift-Final
git lfs pull
```

### 2 · 打开 / Open

1. Unity Hub 安装 **6000.4.10f1**。  
   Install **Unity 6000.4.10f1** through Unity Hub.
2. **添加 → 从磁盘添加项目**，选择 `End-of-Shift-Final` 文件夹。  
   Choose **Add → Add project from disk**, then select `End-of-Shift-Final`.
3. 等待导入与编译完成，打开 **`Assets/Resources/Scenes/first.unity`**。  
   Wait for imports and compilation, then open **`Assets/Resources/Scenes/first.unity`**.
4. 点击 **▶ Play → START → CONTINUE**，从桌上的员工手册开始。  
   Click **▶ Play → START → CONTINUE**. Begin with the handbook on the desk.

开始页 **Settings → Language** 可切换中英文，设置会自动保存。  
Switch between English and Simplified Chinese in **Settings → Language**. Your preference is saved.

## 操作 / Controls

| 输入 / Input | 操作 | Action |
| :--- | :--- | :--- |
| **W A S D** | 移动 | Move |
| **鼠标 / Mouse** | 观察 | Look around |
| **E** | 交互、拿取、阅读 | Interact, pick up, read |
| **Q** | 放下手持物品 | Put down held items |
| **鼠标左键 / Left click** | 使用枪、探测器，点击界面 | Use equipment; operate UI |
| **监控箭头 / Monitor arrows** | 切换监控 | Switch camera feeds |
| **ESC** | 关闭阅读与监控界面，或打开暂停 | Close reading/camera views; otherwise pause |

气阀、电闸解谜中的 ESC 打开暂停，继续后回到当前解谜。暂停页侧边箭头切换音量页；笔记下方也有返回按钮。  
During gas and breaker puzzles, ESC opens pause; resuming returns to the puzzle. Side arrows switch to audio settings. Notes also have a back button below the page.

### 制作说明 / Production notes

本版本使用原生绘制的控制面板与纸张 UI，开始页和结局通过 Unity 场景实时渲染。游戏过程中的鬼影保留 AI 生成贴图，代码与设计有 AI 辅助；历史美术资源状态见素材记录。第三方素材沿用各自授权。

This version uses native geometry for panels and paper UI, with Unity-rendered scenes for the menu and endings. In-game ghost cutouts remain AI-generated; code and design were AI-assisted. See the asset register for historical artwork. Third-party assets retain their respective licenses.
