## 打开项目

1. 安装 **Unity 6000.4.10f1（Unity 6.4）**，版本以 `ProjectSettings/ProjectVersion.txt` 为准。
2. Unity Hub → 添加／从磁盘添加项目，选择下载的 `End-of-Shift-Final` 文件夹。
3. 等待资源导入、依赖安装与脚本编译完成。首次打开会生成 Library 缓存。
4. 打开 **`Assets/Resources/Scenes/first.unity`**，点击顶部 **▶ Play**。
5. 点击 **START → CONTINUE**，阅读控制室桌上的员工手册，然后查看监控开始值班。

开始页 Settings 可以切换 English／简体中文，设置会自动保存。若需要独立运行程序，在 Unity Build Profiles 中选择 Windows 并将 `first` 加入场景列表，构建到项目外的输出目录；构建后再做目标电脑上的完整试玩。

## 故事与游戏流程

你独自值守地下实验设施。三路监控、墙上的正常状态照片、员工手册和前任留下的笔记，帮助你识别逐渐出现的异常。

主要流程：阅读手册 → 查看监控 → 走廊异常物品处理 → 气阀压力调节 → 射击室鬼影 → 电闸修复 → 样本探测与处理 → 返回监控 → 最终控制器作出选择。处理异常后回到监控观察，新异常通常在观察约十秒后出现，伴随短暂警报与灯光、屏幕干扰。探测阶段限时三分钟。

- 气阀：按住增加压力，松开降低压力，在安全区保持稳定，完成三个通道。
- 电闸：旋转三个连接器接通线路，记住彩灯顺序，再按该顺序拉下三个拉杆。
- 发送记录结局：黑影从实验室进入电梯，关门并随电梯离开，危险可能传到外界。
- 封锁设施结局：电梯门始终关闭，鬼留在实验室并朝主角逼近；外界安全，主角仍被困其中。
- 超时失败：播放第一视角被抓镜头。结果采用黑底，实时画面居中，字幕和按钮位于下方。

可选内容包括五个小机器人收集与桌面展示、食物和饮料、音乐播放器及剧情笔记。

## 操作

| 输入 | 功能 |
| --- | --- |
| WASD | 移动 |
| 鼠标 | 观察 |
| E | 交互、拿取、阅读、进入控制界面 |
| Q | 放下手持物品 |
| 鼠标左键 | 使用枪或探测器、点击界面 |
| 监控箭头 | 切换监控 |
| ESC | 关闭笔记、照片或监控；普通游玩时打开暂停 |
| 解谜界面中的 ESC | 打开暂停，不跳过气阀或电闸流程 |

暂停页通过侧边箭头切换音量页，退出直接退出。笔记底部有返回按钮。结局播放结束后显示重新开始、退出按钮。

## 交付版本改动与素材边界

- 开始和介绍页使用实际控制室的实时场景；介绍页为正面近景。保留屏幕干扰、红灯频闪及轻微椅子晃动。
- 电闸、气阀、暂停／音量及最终选择控制器采用原生 UI 几何、可点击控件和实时文字。
- 书本、便利贴和无格线记录纸使用原生绘制背景，保留双页手册、中英文正文和返回功能。
- 两个结局及失败画面采用场景网格、材质和相机制作的短镜头，结局黑影使用程序网格。
- **游戏过程中的射击、超时逼近鬼影，按作者要求保留原来的 AI 生成贴图。本版本不是“全项目零 AI 素材”。**代码与布局亦由 AI 辅助制作。
- 停用的菜单、解谜和结局旧图仍有历史资源保留，不应标注为非 AI 制作。此次替换的暂停、最终控制器与纸张旧图已移至本地 Assets 外归档，不纳入本次提交。

用于禁止任何 AI 素材的场合时，还需进一步处理保留鬼影及历史资源，并核对 AI 辅助代码／设计的要求。
