# End of Shift

一个以地下实验设施夜班为背景的第一人称恐怖游戏。观察监控、对照房间照片、处理异常，并在值班结束时作出最后的选择。

## 打开项目

1. 安装 Unity **6000.4.10f1**（Unity 6.4），建议使用项目记录的同一版本。
2. 安装 Git LFS，然后克隆仓库并获取源文件：

   ```powershell
   git clone https://github.com/NANN-nn/Zero-duty.git
   cd Zero-duty
   git lfs pull
   ```

3. 在 Unity Hub 中添加克隆得到的项目文件夹，等待资源导入与脚本编译完成。
4. 打开 `Assets/Resources/Scenes/first.unity`，点击 Play。
5. 通过开始界面进入游戏，阅读员工手册后开始值班。

开始界面的 **Settings → LANGUAGE**（中文界面为“设置 → 语言”）可以在 English 和简体中文之间切换，立即生效并自动记住选择。菜单、介绍、操作提示、心里话、员工手册与笔记、解谜状态及结局字幕均支持双语；中文标题为“夜尽之前”，英文标题为 END OF SHIFT，键位字母不变。气阀面板不显示状态文字或计时，保留灯光、压力条、通道编号及“按住 / HOLD”按钮提示。

仓库保存 Unity 项目源码和资源；当前不包含可直接运行的 Windows 发行包。

## 操作

| 输入 | 操作 |
| --- | --- |
| WASD | 移动 |
| 鼠标 | 观察 |
| E | 交互、拿取物品 |
| Q | 放下手持物品 |
| 鼠标左键 | 使用枪或探测器；操作界面 |
| 左右箭头按钮 | 切换监控画面 |
| ESC | 关闭笔记、参考图片或监控视图；其他情况下打开暂停菜单 |

进入气阀或电闸面板后，ESC 打开暂停菜单，不退出解谜。恢复游戏后继续处理，完成后面板自动关闭。

## 内容

- 三路可查看、切换的监控，以及墙上的正常状态参考照片。
- 走廊异常物品、气阀压力调节、射击室鬼影、电闸线路与拉杆、样本探测与销毁。
- 异常处理限时、画面与灯光干扰、逐步逼近的鬼影和失败画面。
- 结束时的两种选择及对应结局插画。
- 员工手册和编号笔记、可收集的小机器人、食物与音乐播放器。
- 开始界面、介绍页、暂停与音量设置。

## 项目结构

- `Assets/`：游戏脚本、场景、模型、图片、字体和音频。
- `Packages/`、`ProjectSettings/`：Unity 包依赖和项目配置。
- `ArtSource/`：Blender 原始文件、制作脚本、素材来源记录和逻辑测试。

`Library/`、`Temp/`、本地恢复场景及 Python 缓存不作为新内容上传。大型鬼魂 Blender 源文件使用 Git LFS；游戏使用的渲染帧已包含在 `Assets/Resources/GhostSpirit/` 中。

## 编辑器测试

以下快捷键用于 Unity 编辑器中的 Play 测试，不作为正式游玩流程：

- F3：电闸测试。
- F4：气阀测试。
- F8：射击室测试。
- F9：直接打开结尾选择界面（先离开监控座位）。
- F11：进入值班后，一键收集剩余机器人，播放手册桌上的五机器人展示镜头；再次测试需重新 Play。
- F12：开启或停止 15 秒鬼影逼近预览。
- F6：异常计时进行中，触发失败画面。
